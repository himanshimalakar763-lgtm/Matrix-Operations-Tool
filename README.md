# Matrix Operations Tool

## Project Overview
This project is a Matrix Operations Tool developed using Python and the NumPy library. It allows users to perform various matrix operations such as addition, subtraction, multiplication, transpose, and determinant calculation through an interactive interface.

## Features
- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Matrix Transpose
- Determinant Calculation
- User-friendly Interactive Interface
- Structured Display of Results

## Technologies Used
- Python
- NumPy

## How to Run

### 1. Install Required Library
```bash
pip install numpy
```

### 2. Run the Project
```bash
python main.py
```

## Operations Supported

### Addition
```text
A + B
```

### Subtraction
```text
A - B
```

### Multiplication
```text
A × B
```

### Transpose
```text
Aᵀ
```

### Determinant
```text
det(A)
```

## Sample Input

```text
Matrix A:
[[1, 2],
 [3, 4]]

Matrix B:
[[5, 6],
 [7, 8]]
```

## Sample Output

### Addition
```text
[[ 6  8]
 [10 12]]
```

### Multiplication
```text
[[19 22]
 [43 50]]
```

### Determinant of A
```text
-2.0
```
